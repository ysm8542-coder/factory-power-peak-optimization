# -
2021년 공장 전력·생산·기상 데이터(1시간 단위)로 전력 수요를 예측하고 Peak를 최적화하는 프로젝트. 다변량 LSTM으로 다음 1시간 전력을 예측하고, 예측 오차가 큰 조건(고온·고생산·아침 시간대)을 분석해 반영한 보강+보정 LSTM으로 MAE를 8.74에서 6.34로, RMSE를 12.72에서 9.45로 개선했다. 회귀·XGBoost·SHAP으로 전력 Peak 발생 요인을 분석했으며, MILP 최적화로 생산 목표를 지키면서 전력 Peak와 인건비·전기요금을 줄이는 라인 운영 및 일용직 인원 배치안을 도출했다.

==========================================================================
 공장 전력 수요 예측 · Peak 분석 · 인원 배치 최적화 — 파일 설명
==========================================================================

[실행 순서]

  1. Dataset_processing.ipynb               원본 데이터 전처리
  2. normal_single_variation_lstm.ipynb     단변량 LSTM (기준 모델)
  3. LSTM_AIModel.ipynb / LSTM_AIModel.py   다변량 LSTM (기본 모델)
  4. Make_full_power_pkl.ipynb              예측 결과 · 오차 데이터셋 생성
  5. Error_Driver_Pipeline.ipynb            예측 오차 원인 분석
  6. LSTM_AIModel_Enhanced.py               보강 + 보정 LSTM (개선 모델)
  7. LSTM_Enhanced_Performance.ipynb        개선 모델 성능 리포트
  8. Elecetric_peak_condition_modified.ipynb  전력 Peak 발생 요인 분석
  9. Optimizing31_MILP.ipynb                Peak · 비용 최적화 및 인원 배치

  * 모든 노트북의 입력 데이터는 1번에서 만든 okm_augumented_2021_processed.xlsx 이다.
  * 8번(Peak 요인 분석)은 1번 이후 독립적으로 실행할 수 있다.


--------------------------------------------------------------------------
1. Dataset_processing.ipynb — 원본 데이터 전처리
--------------------------------------------------------------------------
- 2021년 1월~9월, 1시간 단위 공장 전력 · 생산 · 기상 데이터를 점검하고 정제한다.
- 주요 처리
  · 범위를 벗어난 `시간` 값(7/13, 7/15) 복원 및 datetime 연속성 검증
  · 15분 단위 전력값으로 파생 변수 생성 (전력 구간합계 / 최대값 / 최소값 / 변동폭)
  · 결측치 처리: 풍속 · 강수량은 선형 보간, 공장인원은 RandomForest 회귀로 대체
  · 공휴일(대체공휴일 포함)의 요일 코드를 8로 변경
- 입력: okm_augumented_2021.csv
- 출력: okm_augumented_2021_processed.xlsx


--------------------------------------------------------------------------
2. normal_single_variation_lstm.ipynb — 단변량 LSTM (기준 모델)
--------------------------------------------------------------------------
- 전력 사용량(`평균`) 하나만 입력으로 직전 24시간 → 다음 1시간 전력을 예측한다.
- 다변량 모델과 비교하기 위한 기준선(baseline)이다.
- 학습 85% / 테스트 15%, 평가 지표 RMSE · MAE · R²


--------------------------------------------------------------------------
3. LSTM_AIModel.ipynb / LSTM_AIModel.py — 다변량 LSTM (기본 모델)
--------------------------------------------------------------------------
- 전력 · 생산량 · 기상 · 공장인원 등 13개 변수의 직전 24시간으로 다음 1시간 전력을 예측한다.
- 모델 구조: LSTM(64) → Dropout → LSTM(32) → Dropout → Dense(16) → Dense(1)
- 노트북 (LSTM_AIModel.ipynb)
  · 학습 구간 시나리오 A~D 비교 (2 · 3 · 4개 구간 분할 vs 1~9월 전체)
  · 시나리오 D 확장 윈도우(Expanding Window) 검증
  · 시간대별 · 평일/주말별 성능, 전력 급증(40%↑) 탐지 성능 분석
  · 1~9월 전력 · 운영 지표 리포트
- 모듈 (LSTM_AIModel.py)
  · 노트북의 공통 함수(load_data, make_sequences, train_lstm_model, evaluate_model)와
    설정값(FEATURES, TARGET, WINDOW_SIZE)을 정리한 파일. 다른 노트북에서 import 해서 사용한다.
  · 직접 실행하면 시나리오 A~D 성능 비교 결과를 출력한다.


--------------------------------------------------------------------------
4. Make_full_power_pkl.ipynb — 예측 결과 · 오차 데이터셋 생성
--------------------------------------------------------------------------
- LSTM_AIModel.py의 모델(시나리오 D)로 1~9월 전체를 예측하고 실제값 · 예측값 · 오차 · 오차율 ·
  과대/과소 여부 · 입력 조건을 한 표로 저장한다. (오차 원인 분석의 입력)
- 기상 4개 변수(기온 · 습도 · 강수량 · 풍속)를 동시에 예측하는 다중 출력 LSTM도 포함한다.
- 출력: full_df_power_only.pkl / .xlsx, weather_prediction_5cols.xlsx


--------------------------------------------------------------------------
5. Error_Driver_Pipeline.ipynb — 예측 오차 원인 분석
--------------------------------------------------------------------------
- 예측 오차를 허용(±10%) / 중간 / 큰 × 과소 / 과대 그룹으로 나누고, 어떤 조건에서 큰 오차가 나는지 분석한다.
- 분석 방법
  · 시각별 · 변수 구간별 오차 비율
  · 시각 · 근무유형을 통제한 변수 비교 (표준화 차이)
  · 주 단위 블록 교차검증 분류 모델 + permutation 기반 요인별 영향력
- 주요 결과: 생산량 · 인원이 많을 때, 28℃ 이상 고온일 때, 아침 07~11시에 큰 과소예측이 많다.
- 입력: full_df_power_only.pkl
- 출력: Error_Driver_Pipeline_결과.xlsx


--------------------------------------------------------------------------
6. LSTM_AIModel_Enhanced.py — 보강 + 보정 LSTM (개선 모델)
--------------------------------------------------------------------------
- 오차 원인 분석 결과를 반영한 2단계 전력 예측 모델 모듈.
  · 1단계 보강 LSTM: 기존 입력 + 오차 원인 변수(시간대 · 평소/최근 부하 패턴 · 생산/인원 변화 ·
    고온 · 누적 고온 · 다음 시간 계획/예보 값) + peak 가중 학습
  · 2단계 잔차 보정: out-of-fold 잔차로 학습한 GBM 2개(peak 보정형 · 스태킹형) 앙상블
- 8:2 분할(split_82)과 확장 윈도우(expanding_window) 검증, 평가 지표 함수(metrics, peak_metrics)를 제공한다.


--------------------------------------------------------------------------
7. LSTM_Enhanced_Performance.ipynb — 개선 모델 성능 리포트
--------------------------------------------------------------------------
- 일반 LSTM / 보강 LSTM / 보강+보정 모델을 같은 조건에서 학습해 성능을 비교한다.
- 확장 윈도우 기준 MAE 8.74 → 6.34, RMSE 12.72 → 9.45 (일반 LSTM → 보강+보정)
- 시간대별 · 평일/주말별 성능, 7월 고온기 peak 분석, 오차 원인 조건별 개선율, 급증 탐지 성능
- 첫 실행 시 학습 결과를 enhanced_results.pkl에 저장하고 이후에는 불러와서 사용한다 (CPU 기준 약 50분).
- 출력: enhanced_results.pkl, 보강보정모델_성능리포트.xlsx


--------------------------------------------------------------------------
8. Elecetric_peak_condition_modified.ipynb — 전력 Peak 발생 요인 분석
--------------------------------------------------------------------------
- 일별 전력 Peak를 탐지(scipy find_peaks)하고, Peak가 언제 · 어떤 조건에서 생기는지 분석한다.
- 분석 내용
  · 평일 / 주말 Peak 통계 · 발생 시간대 · 계절별 대표 전력 패턴
  · Lag · Rolling 변수를 포함한 OLS 회귀, XGBoost + SHAP 변수 중요도
  · K-Means 계층 분류로 상위 Peak 그룹을 나누고 규칙 기반으로 원인 추정
  · 생산량 구간별 기온 · 습도와 전력의 관계 (히트맵)
- 출력: peak_factor_analysis_result.xlsx


--------------------------------------------------------------------------
9. Optimizing31_MILP.ipynb — Peak · 비용 최적화 및 인원 배치
--------------------------------------------------------------------------
- 월 · 2주 생산 목표를 지키면서 월 최대 전력 Peak를 낮추고, 인건비 + 전기요금을 최소화하는
  라인 가동 시간 · 시간별 생산량 · 일용직 근무 배치를 MILP(scipy HiGHS)로 구한다.
- 구성
  · 전력 예측(ML + 보강+보정 LSTM 연결) + 과소예측 방지용 시간대 × 달 차등 안전마진
  · 1인당 생산량 ML (보수적 하위 30% 분위)
  · 라인 · 생산 MILP ↔ 일별 정수 근무패턴 배치 반복 (LP 쌍대값으로 인건비 단가 갱신)
  · 일용직 근무 규칙: 2 · 3 · 4시간 단기 근무, 5시간 이상 30분 단위, 무급 휴게, 단기 근무자 비율 50% 미만
  · 월별 리포트 · 제약 검증 · 인건비 분해
  · 1~9월 인원 배치표, 하루 목표 생산량별 인원 배치, 하루 계획 도구(월 · 생산량 · 강수 입력)
- 출력: Optimizing31_MILP_결과.xlsx, 인원배치표_1-9월.xlsx, 하루목표별_인원배치.xlsx,
        일일_인원배치_*.xlsx / .png
